## High

### 1. "Let's fix them" on Remy's offer does nothing
Steps: owner, resume with 2+ lines without numbers → Home → "Remy noticed something … Let's fix them".
Happens: the chat opens with "On it. Started fixing your resume with you, one line at a time" and an Undo, then nothing. No line is asked and no fix screen opens.
Expected: the fixing starts. On the website `POST /api/remy/act` returns a `start` / `resumeFix` action and `startResumeFix()` runs (`client/src/lib/remyDoes.ts`). The app never handles `resumeFix` (no match in `native/src`).
Fix: when the act answer has `kind: "start", ref: "resumeFix"`, open the native "Remy's fixes" screen (the one behind Resume → "Remy can fix N lines") instead of the chat.

## Medium

### 2. Student view shows owners-only parts while "redesign" is Owners only
Steps: More → Student, Admin releases at `redesign: owners` → Home.
Happens: the "Remy noticed something" card still shows (and the rest of the redesigned Home).
Expected: the website shows the offer only in owner view (`client/src/App.tsx`: `{ownerView && <RemyOffer />}`). Smallest fix: gate the offer with `useOwnerView()`. The bigger question (what students see in the app before the redesign is released) is your open question to the lead; see the answer in `status/lead.md`. This goes away once The Big Upgrade is released.

### 3. Asking from Remy's office makes you send twice
Steps: My Path → type a question in the office box → tap the arrow.
Happens: the chat opens with the question in the input box, not sent.
Expected: it asks it. `path.tsx` says "with a question, it asks it there", but `askRemy()` only pre-fills (`remy.tsx` `setText(ask)`). Send it when it came from the office (keep pre-fill for suggested questions if you want the student to edit those).

### 4. "This week's big move" opens the website for something the app does natively
Steps: My Path → "Add a real number to 1 bullet" → "Let's do it".
Happens: the website's `/resume?tab=base` opens in the signed-in sheet.
Expected: the native "Remy's fixes" screen, which asks for exactly that number. Worth checking every `go("/resume…")` the same way.
