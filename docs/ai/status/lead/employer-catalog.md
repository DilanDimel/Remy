Employer catalog (Dilan, Nov 25: "connect the entirety of the United States", proposal https://claude.ai/artifact/RUo7WdLRZSazm8pCgdCHeG, Phase 1). `server/jobs/catalog.ts` reads about 15,600 companies' public job boards (`server/data/catalog-boards.tsv`, StoreSignal directory, CC BY 4.0, credited in `server/data/SOURCES.md`): Greenhouse, Lever, Ashby, Workable, Recruitee, SmartRecruiters. Each sweep (hourly via the Cloudflare cron) reads the part (1/24) read longest ago, skipping parts read in the last 20 h; keeps US postings with a student-level title (`studentTitle` in sources.ts, same rule discoverJobs uses; `inUS` in fit.ts) with up to 6,000 chars of text; writes `catalog/part-N` + `catalog/meta` sealed to R2. Never Supabase. Searches add `CATALOG_BOARD` (one source, all parts from memory, about 7-8k postings) and discoverJobs filters it like any employer. Live test of one part: 646/652 boards, 23k postings, 317 kept, 216 s at 8 at a time (now 4), 1.3 MB. Searches load parts in the background (never wait on R2); discoverJobs builds requirements only for the openings it keeps (8,000 postings: 3.5 s → 0.5 s). Owners see reach on Admin → Openings. Also: `fetchBoard` reads Workable and Recruitee; native country names (Deutschland…) count as abroad. USAJOBS key set in Render Nov 25.
