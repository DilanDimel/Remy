DigitalOcean limits (Nov 27, lead watch thread, Dilan said go). Answers demetre-5. Checked the live app spec on DigitalOcean: R2_ACCOUNT_ID, R2_BUCKET, R2_ACCESS_KEY_ID, R2_SECRET_ACCESS_KEY, WS_CACHE_KEY, CRON_SECRET and DB_SSL_CA are all set (no DB_SSL_INSECURE). DB_SIZE_LIMIT_MB, DB_EGRESS_LIMIT_GB and MEMORY_LIMIT_MB were not set, so the code defaults (Supabase's 500 MB and 5 GB, Render's 512 MB) gave false warnings. Instead of editing the app spec (a full-spec replace that would have to copy every encrypted secret), the defaults now match DigitalOcean: database 10240 MB (`remy-db`, 10 GiB storage), memory 2048 MB (`apps-s-1vcpu-2gb`), database transfer 250 GB a month (a load signal only; DigitalOcean doesn't bill it). Env vars still override them.
