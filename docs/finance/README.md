# Costs

Owned by Julio (see `docs/ai/owners.json`). Current and projected costs for running Remy: AI, hosting (Render), database (Supabase), email, domains and app stores.

This repo is public: write the model and its assumptions here, never account numbers, invoices or card details.

Where the numbers come from today:
- **AI spend:** logged per call and summed on the owners' dashboard (`server/platform/admin.ts`).
- **PR AI cost:** the optional `AI cost:` line in each PR description (what the AI tools cost to build it).
